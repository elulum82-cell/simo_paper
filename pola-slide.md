# Pola slide default (bila rujukan tidak menetapkan struktur)

**Paparan keputusan/rapat**: Judul → Latar & tujuan → Ringkasan eksekutif (3 angka kunci) → Temuan 1..n (satu per slide, judul-kesimpulan) → Opsi/analisis → Rekomendasi → Tindak lanjut & penanggung jawab → Lampiran.

**Laporan hasil kajian**: Judul → Konteks → Metode singkat → Hasil utama (grafik) → Pembahasan → Implikasi → Kesimpulan → Rencana lanjut.

**Proposal/pendanaan**: Judul → Masalah → Solusi → Dampak terukur → Rencana kerja & jadwal → Anggaran ringkas → Tim → Permintaan.

## Pilihan visual menurut jenis isi
- Perbandingan waktu → grafik garis; perbandingan kategori → batang; komposisi → donat/batang bertumpuk (maks. 5 irisan)
- Satu angka penting → angka besar + konteks satu baris
- Proses/tahapan → diagram alur 3–5 langkah dengan ikon
- Daftar kriteria/opsi → kartu 2–4 kolom atau tabel ringkas
- Jadwal → timeline horizontal
- Kutipan/ketentuan dari dokumen rujukan → kotak sorot dengan rujukan halaman
