# Checklist kualitas manuskrip

Gunakan pada Tahap 6. Tandai tiap butir; laporkan yang gagal ke pengguna.

## Argumen dan kebaruan
- [ ] Gap penelitian dinyatakan jelas dan didukung sitasi
- [ ] Tujuan/pertanyaan penelitian satu kalimat tegas
- [ ] Kontribusi/kebaruan eksplisit (di akhir Pendahuluan dan Kesimpulan)

## Konsistensi
- [ ] Tujuan ↔ metode ↔ hasil ↔ kesimpulan saling menjawab
- [ ] Angka di Abstrak, Hasil, dan Kesimpulan identik
- [ ] Istilah, singkatan, satuan, dan notasi konsisten
- [ ] Kesimpulan tidak memuat data atau argumen baru

## Metode dan data
- [ ] Cukup rinci untuk direplikasi
- [ ] Sumber, periode, dan ukuran data jelas
- [ ] Asumsi dan keterbatasan dinyatakan
- [ ] (Pemodelan) parameter bersumber, ada validasi dan analisis sensitivitas

## Penyajian
- [ ] Setiap tabel/gambar bernomor, berjudul mandiri, dan dirujuk di teks
- [ ] Gambar dibuat dari data nyata pengguna
- [ ] Abstrak 150–250 kata (atau sesuai jurnal), tanpa sitasi

## Referensi dan etika
- [ ] Setiap sitasi di teks ada di daftar pustaka dan sebaliknya
- [ ] Format sitasi sesuai jurnal (APA/IEEE/Vancouver, dll.)
- [ ] Referensi tak terverifikasi ditandai [VERIFIKASI]
- [ ] Tidak ada penyalinan teks sumber (parafrase + sitasi)
- [ ] Penanda [DATA DIBUTUHKAN] semuanya dilaporkan
- [ ] Catatan etika: izin data, persetujuan etik, pengungkapan penggunaan AI

## Simulasi reviewer (tulis 3–5 poin)
Bayangkan reviewer yang skeptis: apa keberatan terkuat terhadap kebaruan, metode, dan kesimpulan? Tulis dan sarankan perbaikannya.
